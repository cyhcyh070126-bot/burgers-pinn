# Attribution and licensing

This repository presents Yanghao Chen's computational study of strong-form
physics-informed neural networks for a Burgers Riemann problem. It packages
the project's archived standard and global artificial-viscosity implementations.
Source identities and packaging changes are recorded in `docs/reproducibility.md`.

PyTorch, NumPy, Matplotlib, Pillow, and PyMuPDF are external dependencies;
their own licenses apply. Times New Roman font files are not distributed.

This initial public release does not assign a blanket open-source license to
the project-specific code or research figures. Contact the repository owner
through GitHub regarding reuse permissions.
